# Open source et licences

## Introduction
Le mouvement du free software, actif depuis les débuts de l'ère informatique, se caractérisait par une distribution pratiquement gratuite du logiciel. La distribution des seuls binaires et l'impossibilité de corriger les bugs ou de développer de nouvelles features ont renforcé la nécessité de distribuer le code sous des licences capables de donner de la liberté aux utilisateurs.

Un logiciel A BESOIN d'une licence.

Caractéristiques d'une licence open source :
- redistribution libre,
- code source,
- œuvres dérivées,
- si l'intégrité du code source de l'auteur est exigée, alors usage de patches,
- aucune discrimination contre des personnes ou des groupes,
- aucune discrimination de secteurs,
- distribution de la licence,
- la licence ne doit pas être spécifique à un produit/distribution,
- la licence ne doit pas contaminer d'autres logiciels,
- la licence doit être technologiquement neutre.

## Licences
Quelques licences open :

- `MIT`
- `GPL`
- `LGPL`

## Creative Commons
Dans le domaine des compositions artistiques de toute nature, on utilise les licences Creative Commons avec les attributs suivants :

- `BY` Attribution à l'auteur requise,
- `ND` (NoDerivatives) Modifications non autorisées,
- `NC` (NonCommercial) Seuls les usages non commerciaux sont autorisés,
- `SA` (ShareAlike) Les œuvres dérivées doivent être distribuées sous la même licence.
