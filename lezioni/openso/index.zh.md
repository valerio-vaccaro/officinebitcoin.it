# Open source 与许可证

## 介绍
free software 运动从计算机时代早期就已经活跃，其特点是软件几乎可以免费分发。只分发二进制文件，以及无法修复 bugs 或开发新的 features，进一步强化了以能够赋予用户自由的许可证来分发代码的必要性。

软件需要许可证。

open source 许可证的特点：
- 自由再分发，
- 源代码，
- 衍生作品，
- 如果要求保持作者源代码的完整性，则使用 patches，
- 不歧视个人或群体，
- 不歧视使用领域，
- 许可证的分发，
- 许可证不得专属于某个产品/发行版，
- 许可证不得污染其他软件，
- 许可证必须保持技术中立。

## 许可证
一些 open 许可证：

- `MIT`
- `GPL`
- `LGPL`

## Creative Commons
在任何形式的艺术创作领域，通常使用带有以下属性的 Creative Commons 许可证：

- `BY` 要求署名作者，
- `ND` (NoDerivatives) 不允许修改，
- `NC` (NonCommercial) 只允许非商业用途，
- `SA` (ShareAlike) 衍生作品必须以相同许可证分发。
