# Open Source und Lizenzen

## Einführung
Die Free-Software-Bewegung, die seit den Anfängen des Computerzeitalters aktiv ist, war durch eine praktisch kostenlose Verteilung von Software geprägt. Die Verteilung nur der Binärdateien und die Unmöglichkeit, Bugs zu beheben oder neue Features zu entwickeln, verstärkten die Notwendigkeit, Code unter Lizenzen zu verbreiten, die den Nutzern Freiheit geben können.

Software BRAUCHT eine Lizenz.

Merkmale einer Open-Source-Lizenz:
- freie Weiterverbreitung,
- Quellcode,
- abgeleitete Werke,
- falls die Integrität des Quellcodes des Autors verlangt wird, dann Verwendung von Patches,
- keine Diskriminierung von Personen oder Gruppen,
- keine Diskriminierung von Einsatzbereichen,
- Verteilung der Lizenz,
- die Lizenz darf nicht spezifisch für ein Produkt/eine Distribution sein,
- die Lizenz darf keine andere Software kontaminieren,
- die Lizenz muss technologisch neutral sein.

## Lizenzen
Einige offene Lizenzen:

- `MIT`
- `GPL`
- `LGPL`

## Creative Commons
Im Bereich künstlerischer Werke jeder Art werden Creative-Commons-Lizenzen mit folgenden Attributen verwendet:

- `BY` Namensnennung des Autors erforderlich,
- `ND` (NoDerivatives) Änderungen nicht erlaubt,
- `NC` (NonCommercial) Nur nicht-kommerzielle Nutzungen sind erlaubt,
- `SA` (ShareAlike) Abgeleitete Werke müssen unter derselben Lizenz verbreitet werden.
