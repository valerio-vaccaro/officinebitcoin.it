# Open source и лицензии

## Введение
Движение free software, активное с первых лет компьютерной эпохи, характеризовалось практически бесплатным распространением программного обеспечения. Распространение только бинарных файлов и невозможность исправлять bugs или разрабатывать новые features усилили необходимость распространять код по лицензиям, способным давать пользователям свободу.

Программному обеспечению НУЖНА лицензия.

Характеристики open source лицензии:
- свободное перераспространение,
- исходный код,
- производные произведения,
- если требуется целостность исходного кода автора, то использование patches,
- отсутствие дискриминации людей или групп,
- отсутствие дискриминации областей применения,
- распространение лицензии,
- лицензия не должна быть специфичной для продукта/дистрибутива,
- лицензия не должна заражать другое программное обеспечение,
- лицензия должна быть технологически нейтральной.

## Лицензии
Некоторые open лицензии:

- `MIT`
- `GPL`
- `LGPL`

## Creative Commons
В области художественных произведений любого типа используются лицензии Creative Commons со следующими атрибутами:

- `BY` Требуется указание автора,
- `ND` (NoDerivatives) Изменения не разрешены,
- `NC` (NonCommercial) Разрешено только некоммерческое использование,
- `SA` (ShareAlike) Производные произведения должны распространяться по той же лицензии.
