# HAN SOLOminer und Nerdminer

## Einführung
HAN SOLOminer ist ein "Spiel", das Satoshi Spritz erklären kann, was Mining ist und wie es durch die Verbindung mit einem Pool über stratum funktioniert; aus diesem ersten Prototyp entstand nerdminer.

Die Difficulty von Bitcoin ist so hoch, dass Nerdminers niemals einen Block minen werden (und eine Million nerdminers ebenso wenig).

## Unterstützte Hardware

- LILYGO T-Display S3 
- ESP32-WROOM-32, ESP32-Devkit1
- LILYGO T-QT pro 
- LILYGO T-Display 1.14 
- LILYGO T-Display S3 AMOLED 
- LILYGO T-Dongle S3 
- ESP32-2432S028R 2.8"
- ESP32-cam 
- M5-StampS3
